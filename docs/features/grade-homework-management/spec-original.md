# 성적/과제 관리 (Phase 5) — 초기 아이디어

ROADMAP.md 2주 데모 계획 11~13일차, Phase 5 항목 그대로:

- [ ] 학교 성적(내신 등)은 별도 메뉴가 아니라 학생 상세 페이지(`student-detail-page.tsx`)에서 입력/조회
- [ ] 모의고사 관리 메뉴 신설 (학원 자체 시험 성적 입력/조회, 학생별·과목별)
- [ ] 과제 등록 및 제출/완료 현황 체크 — 기존 '성적/과제 관리' 메뉴는 '과제 관리'로 개편

## 배경

- 실사용자: 비개발자인 수학 학원 강사, 담당 학생 약 40명.
- 과목은 수학 단일 (수학 학원).
- 현재 `/grades` 라우트(`grades-page.tsx`)에 성적+과제가 정적 목업 테이블로만 존재. 입력/수정/삭제 기능 없음.
- 현재 `MOCK_GRADES`(`src/mocks/grades.ts`)는 과목이 수학/영어/국어로 섞여 있고 시험명이 자유 텍스트임 —
  실제 방향(수학 단일, 학교 성적 vs 모의고사 구분)과 맞지 않아 재설계 필요.
- 데이터 계층은 아직 mock 기반(`src/mocks/*.ts` + `src/types/*.ts`), 백엔드/DB는 미착수.
