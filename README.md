# 학생 관리 시스템

학원 강사(약 40명 학생 담당)를 위한 학생 관리 웹 애플리케이션입니다.

## 배경

학원은 기존에 엑셀로 학생 정보를 관리하고 있습니다. 이 시스템은 엑셀 워크플로우를 대체하지 않고 병행하면서, 성적 분석·숙제 관리 등 엑셀로는 하기 어려운 기능을 보완하는 것을 목표로 합니다.

## 주요 기능

- **학생 관리**: 학생 정보 등록/조회/수정
- **반 관리**: 수강반 생성 및 캘린더 기반 일정 관리, 반별 학생 배정
- **출결 관리**: 학생별 출결 상태(출석/지각/조퇴/결석 등) 세분화 기록
- **성적/과제 관리**: 시험/과목별 성적 기록 및 추이 확인, 과제 등록·제출 현황 추적
- **수강료 관리**: 반별 수강료·교재비 청구 및 수납 처리
- **상담 관리**: 학생별 상담 기록 및 이력 관리
- **AI 분석**: 성적 추이 및 취약 과목 분석, 학생별 맞춤 코멘트·리포트 생성
- **PDF 다운로드**: 학생 개인 성적표/리포트 출력
- **엑셀 연동**: 학생/성적 데이터 엑셀 가져오기·내보내기 (학원의 엑셀 관리 방식과 호환)

상세 단계별 계획은 [ROADMAP.md](./ROADMAP.md) 참고.

## 기술 스택

- **프론트엔드**: React 19 + TypeScript + Vite
- **백엔드**: Node.js + Express
- **데이터베이스**: PostgreSQL
- **배포**: 클라우드 배포 (프론트 Vercel, 백엔드/DB Railway 또는 Render 예정)

## 개발 환경 실행

```bash
npm install
npm run dev
```
